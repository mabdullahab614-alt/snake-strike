## `// SYSTEM_OVERVIEW`

> **Snake Strike** is a fully browser-based neon arcade game inspired by the classic Snake, rebuilt from scratch with a dark terminal aesthetic, procedural Web Audio sound effects, three difficulty tiers, and a slick animated UI — **no frameworks, no dependencies, pure HTML + CSS + JS**.

<br/>

<div align="center">

| ⚡ Instant Play | 🎵 Real Sounds | 🏆 High Scores | 📱 Mobile Ready |
|:-:|:-:|:-:|:-:|
| Zero install needed | Web Audio API | Per-difficulty leaderboard | D-pad touch controls |

</div>

---

## `// FEATURES`

<table>
<tr>
<td width="50%">

### 🎮 Gameplay
- ✅ Wall collision — instant death on impact
- ✅ Self-collision detection
- ✅ Regular food (+10 pts) with pulse animation
- ✅ Rare golden ★ food (+50 pts, timed)
- ✅ Auto-restart after Game Over (2.5s)
- ✅ Level system — speed increases every 50 pts

</td>
<td width="50%">

### 🖥️ Interface
- ✅ Full neon terminal UI with Orbitron font
- ✅ Main menu with LAUNCH / MODE / SPECS / TERMINATE
- ✅ System Specifications screen
- ✅ Animated title with CRT flicker effect
- ✅ Game Over overlay with RESTART + EXIT buttons
- ✅ Pause / resume with `P` key

</td>
</tr>
<tr>
<td width="50%">

### 🔊 Audio (Web Audio API)
- ✅ Eat food — layered sine + square blip
- ✅ Eat golden food — triple ascending chime
- ✅ Death — sawtooth crash drop
- ✅ Level up — 3-note fanfare
- ✅ UI clicks — subtle feedback beep
- ✅ Zero audio files — 100% procedural

</td>
<td width="50%">

### ⚙️ Difficulty Modes
| Mode | Start Speed | Min Speed |
|------|------------|-----------|
| 🔵 LOW | 220ms | 120ms |
| 🟢 NORMAL | 150ms | 70ms |
| 🔴 HIGH | 90ms | 40ms |

Each mode has its own **separate high score**.

</td>
</tr>
</table>
