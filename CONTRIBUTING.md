# Contributing to Snake Strike

First off — thank you for considering contributing! 🐍

## 🚀 Getting Started

1. **Fork** the repository
2. **Clone** your fork:
   ```bash
   git clone https://github.com/YOUR_USERNAME/snake-strike.git
   cd snake-strike
   ```
3. Open `index.html` in your browser — no build step needed.
4. Make your changes, test them, then submit a PR.

## 📐 Code Style

- Plain HTML, CSS, JavaScript — no frameworks
- Use `camelCase` for JS variables and functions
- Keep CSS custom properties in `:root`
- No external libraries or npm packages
- Comment only non-obvious logic

## 🐛 Reporting Bugs

Use the **Bug Report** issue template. Include:
- Browser + OS
- Steps to reproduce
- Screenshot if possible

## 💡 Suggesting Features

Use the **Feature Request** issue template. Describe the problem it solves, not just the solution.

## 🔀 Pull Request Process

1. Branch off `main`: `git checkout -b feature/your-feature`
2. Make focused, small commits
3. Test in Chrome and Edge minimum
4. Open a PR using the PR template
5. Wait for review from [@mabdullahab614-alt](https://github.com/mabdullahab614-alt)

## 📜 Code of Conduct

Be respectful. No harassment, discrimination, or toxic behaviour will be tolerated.
