# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 2.0.x   | ✅ Yes    |
| 1.0.x   | ❌ No     |

## Reporting a Vulnerability

Snake Strike is a client-side browser game with no backend, no database, and no user data collection. It uses only:
- `localStorage` for saving high scores locally in the user's own browser
- Google Fonts CDN (read-only)
- GitHub Pages static hosting

There is no server, no authentication, and no sensitive data.

If you do find a security concern (e.g. a malicious dependency in a fork, XSS in a future version), please **do not open a public issue**. Instead:

1. Email: **asoftwarer4.5@gmail.com**
2. Subject line: `[SECURITY] snake-strike — <brief description>`
3. Include steps to reproduce and potential impact

You will receive a response within 48 hours.
